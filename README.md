## ⚠️ Важно

DTM — **вспомогательный инструмент**.

- Приложение **не гарантирует 100% отправку** сигналов SOS и сообщений: доставка зависит от связи, разрешений и настроек телефона, а также от работы SMS, WhatsApp и Telegram.
- DTM **не заменяет работу с психотерапевтом**, психологом или врачом и не является медицинской помощью.
- **При угрозе жизни звоните 112.**

## Что умеет

**Безопасность**
- Вход по PIN-коду и отпечатку пальца, блокировка после нескольких неверных попыток
- Тревожный PIN — открывает безобидный блокнот вместо настоящих данных
- Быстрый выход: приложение закрывается и исчезает из списка недавних
- Запрет скриншотов и пустая миниатюра в списке приложений
- Экстренное удаление всех данных

**SOS**
- Удержание кнопки 1,5 секунды — СМС с геолокацией доверенным контактам
- Готовые сообщения в WhatsApp и Telegram
- «Безопасный круг»: тексты для друзей — «позвони мне», «приди ко мне», «забери меня»
- Звонок 112 в одно касание

**Доказательства**
- Диктофон: запись в фоне, шифрование, отпечаток SHA-256, сетевое время и координаты
- Сейф: документы, фото повреждений, скриншоты — AES-256, не попадают в галерею
- Дневник событий с фото, видео и голосовыми заметками
- Отчёт для юриста или полиции

**Поддержка**
- Отметка состояния в любой момент и график
- Дневник снов, дневник режимов (схема-терапия), дневник СМЭР
- Карточки ДПТ, КПТ, заземления, кризисных состояний, план безопасности
- «Карта реальности» — личный текст против чувства вины
- Тесты и раздел «Права до 18 лет»
- Телефоны помощи

**Прочее**
- Резервная копия всех данных в файл, зашифрованный вашим паролем
- Обновления из GitHub Releases прямо в приложении
- Настраиваемый главный экран, светлая и тёмная темы

## Приватность

- Все данные хранятся **только на устройстве** и зашифрованы (AES-256, ключ в Android Keystore).
- Нет аккаунтов, аналитики, рекламы и серверов.
- Облачное резервное копирование Android отключено.
- В сеть приложение обращается только в трёх случаях: за точным временем для записей, при отправке SOS и при проверке обновлений на github.com (при каждом входе, отключается в настройках).

## Установка

1. Скачайте `DTM-x.y.apk` из раздела [Releases](https://github.com/nikaminow/DTM/releases/latest).
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. При первом запуске прочитайте важную информацию и придумайте PIN-код.

Новые версии можно ставить поверх старых — данные сохраняются. Внутри приложения: **Настройки → Проверить обновления**.

Требуется Android 8.0 или новее.

## Сборка из исходников

Нужны JDK 17 и Android SDK (platform 34).

```bash
git clone https://github.com/nikaminow/DTM.git
cd DTM
echo "sdk.dir=/путь/к/Android/Sdk" > local.properties
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

Релизная сборка подписывается ключом, который в репозиторий не входит (`keystore.properties` и `keystore/` в `.gitignore`). Обновления «поверх» возможны только для APK, подписанных тем же ключом.

## Как выпустить обновление

1. Поднимите `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Соберите `./gradlew assembleRelease` (нужен `keystore.properties`).
3. Создайте Release с тегом `vX.Y`, где `X.Y` совпадает с `versionName`, и приложите APK с именем **`DTM.apk`** — приложение скачивает файл именно с таким именем.
4. Приложения пользователей предложат обновление сами при входе или по кнопке **Настройки → Проверить обновления**.
